# Record Attempt — Competition Rocket Simulation

A real 6-DOF flight simulation, built on [RocketPy](https://github.com/RocketPy-Team/RocketPy)
(the Python simulation engine used by university teams at Spaceport
America Cup / IREC), targeting the **10,000 ft AGL COTS-motor** competition
category.

It simulates two configurations end to end — motor burn, ascent, apogee,
dual-deploy recovery, and landing — and compares them:

| Config | Apogee (AGL) | Max Mach | Max accel | Static margin (rail exit) |
|---|---:|---:|---:|---:|
| Baseline | 10,845 ft | 0.860 | 10.7 g | 2.28 cal |
| Record Attempt | 11,965 ft | 0.954 | 11.9 g | 1.64 cal |

The record-attempt configuration gains **+1,120 ft (+10.3%)** over the
baseline by cutting dry mass and re-optimizing the fin set — while
holding a safe, positive stability margin through the whole burn.

## Quickstart

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python src/simulate.py
```

This prints a full flight report for both configs and writes altitude/speed
plots to `outputs/`.

## What's real here vs. what's approximated

**Real, sourced data:**
- **Motor**: Cesaroni Pro75 M1670 — a real, commercially available M-class
  solid motor (`data/motors/Cesaroni_M1670.eng`, manufacturer RASP thrust
  curve). This is a legal COTS motor for the IREC/Spaceport America Cup
  10,000 ft COTS category.
- **Launch site**: Spaceport America, NM (32.990254, -106.974998, 1400 m
  ASL) — the real competition site.
- **Baseline airframe & drag curves**: a validated 127 mm (5 in)
  minimum-diameter airframe with power-on/power-off drag curves from real
  wind-tunnel/CFD-derived data for that exact shape
  (`data/rockets/calisto/`).
- **Fin airfoil**: NACA 0012 lift-curve data (`data/airfoils/`).

**Engineering approximation, clearly flagged in code:**
- The record-attempt drag curve is the baseline curve scaled by the
  estimated change in fin planform area (`src/config.py`, `DRAG_SCALE`),
  assuming fins are ~30% of total vehicle drag. A real record attempt
  needs a re-run through OpenRocket, Missile DATCOM, or CFD once the fin
  geometry is finalized — this approximation is good enough to guide the
  design direction, not to certify a flight.
- Record-attempt inertia is scaled from the baseline by mass ratio, not
  recomputed from an actual mass model / CAD.

## Design story: why the record attempt looks the way it does

The first instinct — shrink the fins to cut drag, since a lighter, smaller
fin set was the obvious lever — **failed in simulation**: a 3-fin set
scaled down ~30% by area came back with a **negative static margin**
(-2.05 cal at ignition). That's not a minor inefficiency, it's a rocket
that tumbles instead of flying straight.

The reason: lightening the dry airframe (14.43 kg → 12.6 kg) while the
motor mass stays fixed means the motor is a *larger fraction* of the
loaded rocket's mass — which pulls the loaded center of gravity **aft**,
toward the fins, eating into the margin between center of gravity and
center of pressure. A lighter rocket needs relatively *more* fin area to
stay stable, not less.

`src/config.py` documents the static-margin sweep that found the fix: fins
were grown back up (n=3, but ~10% larger per-fin than a naive linear
scale-down) until static margin cleared 1.5 cal at ignition and stayed
under ~2.5 cal at burnout — the standard safe band for high-power rocketry.
That configuration still comes out lighter and slightly lower-drag than
baseline, so it still gains altitude — just less than the (unstable, and
therefore meaningless) first guess.

## Project layout

```
src/
  environment.py   Launch site (Environment)
  motor.py         Cesaroni M1670 (SolidMotor)
  config.py        Airframe geometry for both configs + design notes
  rocket.py        Assembles a Rocket from a config (nose/fins/tail/chutes)
  report.py        Flight-report printing and config comparison
  simulate.py       Entry point — run this
data/
  motors/          Real motor thrust curve
  rockets/calisto/ Real drag curves (baseline)
  rockets/generated/ Drag curves scaled for the record attempt (generated by rocket.py)
  airfoils/        NACA 0012 lift data
outputs/           Altitude/speed plots per config (generated)
```

## Next steps toward an actual build

1. Recompute the record-attempt drag curve properly (OpenRocket export or
   CFD) instead of the analytic scale-factor approximation.
2. Build a real mass model (CAD or a bill-of-materials weight budget) to
   replace the mass-ratio inertia scaling.
3. Run a Monte Carlo dispersion analysis (RocketPy supports this natively
   via its `Stochastic` classes) to check the design against wind, motor
   variance, and mass uncertainty before committing to a build.
4. Cross-check apogee/stability against an independent tool (OpenRocket)
   before any real motor goes anywhere near this airframe.
